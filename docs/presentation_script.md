# 발표 대본 — 슬라이드 순서대로

파일: `4조(십분컷)_미니2프로젝트_..._발표자료.pptx` (37장)

슬라이드에는 키워드만, 문장은 발표자가 말한다. ★ = 힘 줄 곳, 나머지는 한두 문장으로 지나간다.
표기: 【화면】 청중이 보는 키워드 · 「말」 발표자 멘트 요지 · → 다리 멘트

## 도입 (1~6장, ~2분)

**1. 표지** — 「LoL 경기는 언제 승부가 결정되는가. 저희는 이 질문 하나를 팠습니다.」

**2. 팀원(4명)** — 이름만. 역할은 한 줄씩.

**3. 발표 순서** — 「데이터를 먼저 의심하고, 예측을 만들고, 이상한 점을 파고들고, 시점을 바꿔봤습니다.」

**4. 진행 구조** — 「각 페이즈는 앞 페이즈가 남긴 질문에서 시작합니다.」
결론(골드 제외·수치)은 여기서 말하지 않는다 — 스포일러 금지.

**5. 게임 기초 30초** — 롤 모르는 심사위원용. 「골드가 돈, 미니언이 주 수입원. 이 두 단어면 됩니다.」

**6. LOLEX 전체 구조** — 「학습은 한 번, 서비스는 매번. 잇는 건 2.2KB 파일 하나입니다.」
→ 「그 학습이 믿을 만한지, 데이터부터 의심했습니다.」

## 섹션 1 · 데이터 검증 (7~11장, ~1분30초)

**7. 섹션 표지** — 제목만.

**8. 데이터 개요** — 「Kaggle 다이아 랭크 9,879판. 결측 0, 중복 0.」

**9. 분할** ★ — 「어떤 전처리보다 먼저 시험지 1,976판을 봉인했습니다.」
「분할이 잘못되면 오류 없이 점수만 거짓이 됩니다 — 그래서 별도 단계로 뒀습니다.」

**10. 분할 진단** — 「겹침 0, 비율 반반, 분포 포개짐 — 네 가지 전부 통과.」

**11. 피처 13개** — 「38개 중 11개가 중복. 남은 걸 차이값 13개로 합쳤더니 정확도가 오히려 올랐습니다.」
표는 한글(영문 컬럼) 병기 — 질문 나오면 영문명으로 짚는다.
→ 「재료는 끝났습니다. 이제 예측을 만듭니다.」

## 섹션 2 · Phase 1 (12~21장, ~4분30초)

**12. 섹션 표지** — 「모델 선정부터, 결과 분석까지.」

**13. 진행 틀 — CRISP-DM** — 「표준 절차의 다섯 단계를 이 순서로 밟았습니다. 업무 이해에서 정한 조건 — '이유를 반드시 낸다' — 가 이후 전부를 결정합니다.」
「분할을 별도 단계로 둔 게 저희 변형입니다 — 잘못돼도 오류가 안 나는 유일한 단계라서요.」

**14. 모델 8종 비교** ★ — 【1위와 2위 0.003 차이】
「점수로는 못 고릅니다. 갈라준 건 '외웠나'와 '왜를 말할 수 있나'.」

**15. 채택** — 「로지스틱만 세 칸 전부 통과. 랜덤포레스트는 중요한 지표는 말해도 방향(+/−)을 못 말합니다.」

**16. NB 보충** — 「정확도는 대등한데, NB는 접전에도 95% 확신을 겁니다.」 시간 없으면 건너뛴다.

**17. 안정성** — 「분할을 10번 바꿔도 전부 목표 통과.」

**18. 홀드아웃** ★ — 【0.7366 · 찍기 대비 +23.8%p】
「9장에서 봉인한 1,976판을 처음 열었습니다. 100판 중 74판.」
→ 「그럼 나머지 26판은 왜 틀렸을까요?」

**19. 골드 승률 곡선** ★ — 【S자 곡선 · 가운데 49.5%】
「골드가 벌어지면 이깁니다. 5천 차이면 99.5%.」
「그런데 경기가 가장 몰린 ±1,000 구간은 49.5% — 동전 던지기. 틀린 26판이 대부분 여기입니다. 모델이 아니라 정보의 한계입니다.」
→ 「점수는 확인했습니다. 그런데 모델이 배운 걸 들여다보니 이상한 게 있었습니다.」

**20. 승리요인 — 음수 발견** ★★ — 【빨간 막대 4개】
「골드가 압도적 1위, 여기까진 예상대로. 그런데 킬·미니언·어시스트·타워가 음수입니다.」
「킬을 많이 한 팀이 불리하다?」

**21. 킬 음수의 원인** ★ — 【킬 → 돈 → 골드차】
「킬의 가치는 이미 골드에 들어가 있습니다. 골드를 아는 모델에게 킬은 새 정보가 아닙니다.」
→ 「그럼 골드를 빼면 어떻게 될까요? 그게 페이즈 2입니다.」 ← 발표 전체의 클리프행어

## 섹션 3 · Phase 2 (22~27장, ~2분30초)

**22. 섹션 표지** — 「빼고 다시 분석했습니다.」

**23. 진단** ★ — 【상관 0.9 · 빨간 점 5개】
「성장 지표들이 한 몸처럼 움직입니다. 그 겹침이 5개의 가중치를 음수로 눌렀습니다.」

**24. 재학습** ★ — 【음수 5개 → 전부 양수】
「골드를 빼니 눌려 있던 5개가 전부 살아났습니다. 킬은 방향이 바뀌고 크기가 5배.」

**25. 대가** ★ — 【정확도 −0.002】
「대가는 0.002. 골드가 특별했던 게 아니라, 다른 지표가 같은 정보를 들고 있던 겁니다.」
→ 「예측과 별개로 남겨둔 갈래 하나 — 경기의 성격입니다.」

**26. 군집 — PCA 실패 → KMeans** ★ — 【부호를 지운 5개】
「정답 없이 묶어봤더니 승패 축으로만 갈렸습니다 — 부호를 남겨두는 한 뭘 해도 승패만 나옵니다.」
「그래서 누가 앞서나를 지웠습니다 — |골드차|·총 킬·총 오브젝트·총 와드·총 CS. KMeans가 실루엣(군집이 잘 갈렸나) 0.2를 유일하게 넘겨 채택했습니다.」

**27. 4종 프로파일** ★ — 【난타전 66% ≈ 운영전 69% · 일방 90%】
「스타일이 달라도 리드의 가치는 같습니다. 일방적인 경기만 이미 끝나 있습니다.」

## 섹션 4 · Phase 3 (28~32장, ~2분)

**28. 섹션 표지** — 「시점을 바꿉니다. 10분 대 15분.」

**29. 데이터 개요 (프로 경기)** — 【Oracle's Elixir · 10,656판 · 지표 5개】
「이번엔 프로 경기입니다 — 페이즈 1 점수와 직접 비교는 안 됩니다. 시점 말고는 전부 고정했습니다.」

**30. 결과** ★ — 【+5.25%p · 10회 반복 일관】

**31. 구간별 이득** ★★ — 【결정된 경기 +0.0 · 접전 +7.8%p】
「5분의 가치는 팽팽한 경기에만 있습니다.」

**32. 종합** ★★ — 【1할은 10분에 끝 · 팽팽한 절반은 그다음 5분에】
「제목의 질문에 답합니다.」

## 섹션 5 · 서비스 · 향후 (33~37장, ~2분)

ML 발표다 — 모델이 화면에서 뭘 하는지(판정) + 시연 + 다음 갈 길만.

**33. 섹션 표지** — 「이 모델을 실제로 돌려봤습니다.」

**34. 판정 4분면** ★ — 【우세승·역전승·역전패·열세패】
「모델 확률이 '앞서 있었다'의 기준입니다. 열세패는 시작을, 역전패는 마무리를 고칩니다.」
「구조는 6장에서 보셨죠 — 계산은 한 곳, 화면엔 sklearn이 없습니다.」

**35. 시연** ★★ — 실제 화면. 검색 한 번, 경기 한 판.
「틀린 판도 그대로 보여드립니다 — 맞힌 판만 고르면 광고입니다.」
「코칭의 숫자는 관찰 기록이지 인과 증명이 아닙니다 — 화면에도 그렇게 적혀 있습니다.」
(막히면: 「방금 34장이 이 화면이 계산하는 전부입니다」 하고 넘어간다.)

**36. 향후 방향성** ★ — 7항목 제목만 읽는다.
「한계가 아니라 다음 할 일들입니다. 접전 판별(시점 확장), 코칭 A/B, 티어 확장(아이언~실버 실측 중), 그리고 수익 모델 — 예측을 팔고, 끝난 판의 기록을 쌓아 파는 것.」

**37. 마무리** — 【골드차 4천이면 끝난 경기, 1천 미만이면 이제 시작】
「이 한 문장이 저희가 데이터로 확인한 답입니다. 감사합니다.」
