### 7-1. 현 모델 검토 — 왜 이 방향인가 (eda_visualization.ipynb + 검토 보완사항 기준)

| 검토 근거 | 발견 | 만약 이어서 한다면 |
|---|---|---|
| EDA 6절 — 성장 지표 6개가 상관 0.42~0.92 한 덩어리 (PC1 38.6%) | 10분 스냅샷 안에서는 피처를 늘려도 정보가 안 늘어남 (2피처 = 전체) | 같은 시점의 피처 추가는 무의미 → **다른 시점·다른 종류의 정보**가 필요 |
| EDA 4절 — ±1,000 구간(33%)이 승률 49.7% | 접전은 10분 정보 자체에 단서가 없음 | 개선은 **시간 축**에서만 나온다 (실험 B가 접전 +7.8%p로 증명) |
| EDA 7절 — WardsPlacedDiff 이상치 13.4%, 효과크기 0.03 | 잡음만 있는 피처 | v2 예측 피처에서 제외 (군집용으로만 유지) |
| EDA 8절 — 실루엣 0.203~0.219로 k 결정 불가 | 경기 유형은 자연적 경계가 아님 | 유형 라벨을 예측 입력에 쓰지 않는 원칙 유지 |
| 검토 보완 — 실험 B에 같은 팀이 학습·시험 양쪽 포함 | 절대 수치 낙관 가능성 | GroupKFold(팀)·시간순 분할을 기본으로 |
| 검토 보완 — 단일 분할 값(0.7394)은 반복 분포의 한 표본 | 성능 보고 방식의 교훈 | 처음부터 시드 반복 분포로 보고 |
| 검토 보완 — Brier 0.1756, 접전 확률의 신뢰도 미검증 | 확률 보정 여부 확인 안 됨 | calibration curve를 표준 산출물로 |

### 7-2. 유사 승패 판별 모델 참조

| 사례 | 방법 | 우리에게 주는 시사점 |
|---|---|---|
| [Real-time eSports Match Result Prediction](https://arxiv.org/pdf/1701.03162) (Dota 2) | 분 단위 골드·경험치·데스 차이로 실시간 예측. 픽밴 같은 사전 정보의 예측력은 경기가 진행될수록 소멸, 실시간 피처는 40분 시점 93.7%까지 상승 | **분 단위 차이 피처만으로 시점–성능 곡선이 성립**한다는 직접 근거. 우리 diff 피처 설계와 동일 계열 |
| [Win Prediction in Multi-Player Esports: Live Professional Match Prediction](https://eprints.whiterose.ac.uk/id/eprint/152931/1/Win_Prediction_in_Multi_Player_Esports_Live_Professional_Match_Prediction.pdf) (Hodge et al.) | 프로 대회에서 실서비스로 검증된 라이브 예측 | 검증 설계(경기 단위 분리, 실황 평가)의 참조 기준 |
| [Interpretable Real-Time Win Prediction for Honor of Kings](https://arxiv.org/pdf/2008.06313) (TSSTN) | 시점별(Two-Stage Spatial-Temporal) 구조로 **시점마다 승리요인을 분해**해 해석 유지 | 시점별 요인 변화 리포트의 모델 사례 — 해석 가능성과 시계열은 양립 가능 |
| [League of Legends: Real-Time Result Prediction](https://arxiv.org/pdf/2309.02449) | LoL 경기 상태 스냅샷으로 분 단위 예측 (트리 부스팅 계열), 시간 경과에 따라 정확도 상승 | LoL에서도 같은 곡선이 재현됨. 데이터 커지면 부스팅 재평가 근거 |
| [Machine learning models for DOTA 2 outcomes prediction](https://arxiv.org/pdf/2106.01782) | LR vs NN vs LSTM 비교 — 시계열 전체를 쓰는 LSTM이 최고(~93%) | 수업 범위(sklearn)와 해석 요구를 넘으므로 참고만 (장기 아이디어) |
| Kaggle 다이아 10분 공개 분석 다수 | 동일 데이터로 70~75% 보고 | 타당성 기준 (우리 0.74가 범위 안) — 시점별 기준선으로도 쓸 수 있음 |

공통 패턴 세 가지: ① 예측력은 **경과 시간의 함수**로 단조 상승 ② 초반 스냅샷에서는 단순 모델과 복잡 모델의 차이가 작고, **데이터 규모·시계열 길이가 커질 때** 복잡한 모델이 이긴다 ③ 사전 정보(픽밴)는 0분 예측 전용이고 인게임 정보가 쌓이면 효력을 잃는다.

### 7-4. 모델 구성 구상 (미확정)

한다면 단계마다 이전 단계가 기준선이 된다 (Constitution 3).

| 단계 | 구성 | 판정 기준 |
|---|---|---|
| M0 기준선 | 시점별 찍기 + **기존 로지스틱을 TIME_POINT=t로 재학습** (5분 간격 모델 뱅크) | 시점–성능 곡선 확보 |
| M1 시점 통합 | 경과 시간 t를 피처로 넣은 단일 로지스틱 (t × 피처 상호작용 포함) | M0 뱅크와 성능 동급이면 채택 (모델 1개 = 운영 단순) |
| M2 부스팅 재평가 | HistGradientBoosting + **단조 제약**(골드차↑→승률↑) — 탈락 사유였던 과적합을 데이터 규모·그룹 분할로 재검증 | M1 대비 +1%p 이상 & 격차 <0.03일 때만 채택 |
| M3 확률 보정 | 채택 모델에 CalibratedClassifierCV(Platt/isotonic) | Brier ≤ 0.1756 · calibration curve 통과 |
| 해석 | 시점별 표준화 계수(M1) 또는 permutation(M2) 리포트 | 두 방법 교차 확인 원칙 유지 |

- 검증한다면: GroupKFold(팀/소환사) 5-fold + 패치 시간순 홀드아웃 병행, 시드 반복 분포로 보고
- 접전 구간(골드차 <1,000)은 항상 별도 행으로 보고
- 참고만: LSTM 등 시계열 신경망은 수업 범위·1코어 제약을 넘어 장기 아이디어로만 기록
