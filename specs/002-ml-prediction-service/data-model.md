## 지킨 규칙

- **예측은 전부 학습된 모델이 한다.** "돈 차이 크면 승리" 같은 규칙을 사람이 써넣지 않는다.
  넣는 순간 "데이터가 검증했다"는 말이 거짓이 되기 때문이다.
- **시험지 봉인.** 데이터를 연습용 7,903판 / 시험용 1,976판으로 먼저 나누고,
  시험용은 마지막 채점 때 딱 한 번만 열었다. 미리 보면 점수가 가짜로 오른다.
- **화면은 보여주기만.** 웹은 예측 파일(predict.py)을 그대로 불러 쓴다.
  계산이 한 곳에만 있어서 화면 숫자와 모델 숫자가 어긋날 수 없고, 자동 대조 테스트도 있다.
- **저장한 모델은 복원 검증.** 파일로 저장한 모델을 다시 불러왔을 때
  똑같은 답이 나오는지 자동으로 확인한다.

# 데이터는 어떻게 생겼나 (data-model)

## 전체 흐름

```
Kaggle CSV — 경기 1판 = 1행, 9,879판 × 40컬럼
  → DB 테이블 lol_matches_10min + 분할 고정 (연습 7,903 / 시험 1,976 · 시드 42 · gameId 정렬)
    → 뷰 v_clean27  — 같은 정보가 두 번 들어간 11개를 뺀 27개
      → 뷰 v_diff13 — "파랑 − 빨강" 차이값 13개  ← 모델 입력 (채택)
        → Pipeline(표준화 + 로지스틱 회귀) = artifacts/model.joblib
          → predict.py 가 돌려주는 답: 확률 · 예측 · 이유 · 경고
            → 백엔드 /api/predict (9524) → 프런트 /api 프록시 (9504) → 화면
```

피처 계산식은 **DB 뷰 한 곳에만** 있다. 파이썬에 같은 식을 다시 만들지 않는다 — 두 곳이 갈라져도 아무도 모르기 때문.

## DB 뷰 4종 (각각 `_train` / `_test` / `_all`)

| 뷰 | 피처 수 | 용도 | 교차검증 정확도 |
|---|---|---|---|
| `v_diff13_*` | 13 | **채택** — 모델 입력 | **0.7369** |
| `v_clean27_*` | 27 | 중복만 뺀 대조군 (블루 16 + 레드 11) | 0.7334 |
| `v_gold2_*` | 2 | 최소 구성 — 돈 차이 + 경험치 차이만 | 0.7328 (시험지) |
| `v_cluster5_*` | 5 (y 없음) | 경기 유형용 — 부호를 지운 절대값·합계 | 예측에 안 씀 |

공통 컬럼: `gameId`(식별자, 모델 입력에서 제외) · `y`(= `blueWins`, 1 승 / 0 패) · `split`(train / test).
**학습에는 `_train` 뷰만** 쓴다. `_test`는 최종 채점 때 한 번만 읽는다.

## 버린 11개 — 같은 정보가 두 번 들어간 컬럼

| 버린 컬럼 | 이유 |
|---|---|
| `redFirstBlood` | = 1 − `blueFirstBlood` |
| `redGoldDiff` · `redExperienceDiff` | = −`blueGoldDiff` · −`blueExperienceDiff` (부호만 반대) |
| `redKills` · `redDeaths` | = `blueDeaths` · `blueKills` |
| `blueGoldPerMin` `redGoldPerMin` `blueCSPerMin` `redCSPerMin` | = 총량 ÷ 10 (10분 고정이라 상수배) |
| `blueEliteMonsters` `redEliteMonsters` | = 드래곤 + 전령 (두 번째로 발견 — 쌍 상관 검사로는 안 잡힘) |

## 모델에 넣는 숫자 13개

전부 "파란 팀 값 − 빨간 팀 값". **양수면 파란 팀이 앞선다**는 뜻.
"단독 효과"는 그 지표 하나만 봤을 때 승패를 얼마나 가르는가(Cohen's d), "모델 순위"는 돈 차이를 이미 아는 상태에서 남는 몫이다.

| 이름 | 뜻 | 단독 효과 | 모델 순위 / 메모 |
|---|---|---|---|
| `GoldDiff` | 돈 차이 | **1.19** | ★ 1위 — 이것 하나로 0.7313 |
| `ExpDiff` | 경험치 차이 | 1.12 | ★ 2위 |
| `KillsDiff` | 킬 차이 | 1.09 | 돈에 이미 반영됨(상관 0.92) → 모델에선 남는 정보 거의 없음 |
| `AvgLevelDiff` | 평균 레벨 차이 | 1.02 | 경험치와 거의 같은 정보(상관 0.92) |
| `AssistsDiff` | 어시스트 차이 | 0.83 | 낮음 |
| `TotalMinionsKilledDiff` | 미니언 처치 차이 | 0.64 | 낮음 |
| `DragonsDiff` | 드래곤 차이 | 0.48 | ★ 3위 — 돈과 별개의 신호 |
| `FirstBlood` | 첫 킬을 파랑이 했나 (0/1) | 0.41 | 낮음 |
| `TotalJungleMinionsKilledDiff` | 정글 몬스터 차이 | 0.34 | 낮음 |
| `TowersDestroyedDiff` | 타워 차이 | 0.33 | 10분엔 거의 0 |
| `HeraldsDiff` | 전령 차이 | 0.23 | 낮음 |
| `WardsDestroyedDiff` | 와드 제거 차이 | 0.16 | 설치보다는 조금 의미 있음 |
| `WardsPlacedDiff` | 와드 설치 차이 | **0.03** | **사실상 무관 (발견!)** · 이상치 13% |

> 화면의 "승리요인"에는 **모델 순위**(돈 > 경험치 > 드래곤)를 쓴다.
> 단독 효과 표를 계수와 섞어 읽으면 "킬을 많이 하면 진다" 같은 오독이 나온다. 정확한 해석은 *"킬은 돈으로 바뀌었을 때만 의미가 있다"*.
> 원래 14개였는데 `EliteMonstersDiff` = 드래곤 + 전령이라 같은 정보가 두 번 들어가서 뺐다 (점수 0.7371 → 0.7369, 차이 없음).

## 입력 허용 범위 — `schema.json`의 근거 (연습 데이터 1% ~ 99%)

| 입력 | 범위 | 벗어나면 |
|---|---|---|
| `GoldDiff` | ±5,900 | "학습 범위 밖" 경고 |
| `ExpDiff` | ±4,650 | 〃 |
| `KillsDiff` / `AssistsDiff` | ±10 / ±14 | 〃 |
| `TotalMinionsKilledDiff` / `TotalJungleMinionsKilledDiff` | ±72 / ±36 | 〃 |
| `WardsPlacedDiff` / `WardsDestroyedDiff` | ±87 / ±8 | 〃 |
| `AvgLevelDiff` | ±1.2 | 〃 |
| `DragonsDiff` · `HeraldsDiff` | −1 / 0 / +1 | 선택 입력 |
| `TowersDestroyedDiff` | −2 ~ +4 | 선택 입력 |
| `FirstBlood` | 0 / 1 | 체크박스 |

## 돈 차이 구간별 승률 — 화면 경고의 근거 (연습 7,903판)

| 10분 돈 차이 | 비중 | 파란 팀 승률 |
|---|---|---|
| −5,000 미만 | 2.1% | 1.8% |
| −5,000 ~ −2,500 | 12.7% | 13.4% |
| −2,500 ~ −1,000 | 18.7% | 26.5% |
| **±1,000 (팽팽)** | **33.1%** | **49.7%** — 사실상 동전 던지기 |
| +1,000 ~ +2,500 | 18.9% | 73.3% |
| +2,500 ~ +5,000 | 12.3% | 86.7% |
| +5,000 초과 | 2.3% | 98.3% |

돈 차이가 ±1,000 안이면 화면에 **"접전 구간 — 예측 신뢰도가 낮습니다"**를 같이 띄운다.
단, 화면에 표시하는 확률은 이 표가 아니라 **모델의 `predict_proba`**다 (이 표를 규칙으로 쓰면 "예측은 모델만" 원칙 위반).

## 경기 유형 (`lol_analysis_10min.gameType`, 연습 7,903판)

| 유형 | 비중 | 특징 | 10분 리드팀 최종 승률 |
|---|---|---|---|
| 운영전 | 41.8% | 킬 9, 조용한 성장 | 68% |
| 난타전 | 32.2% | 킬 15, 싸움 잦음 | 68% |
| 일방적 경기 | 19.3% | 돈 차이 평균 4,192 | **90%** |
| 시야전 | 6.7% | 와드 120개(3배) | 70% |

k=4는 지표(실루엣 0.203~0.219)가 정해준 게 아니라 설명이 성립해서 사람이 고른 값이다. 예측 입력으로는 쓰지 않는다.
