# LoL 경기는 언제 승부가 결정되는가?
### 인게임 시점별 경기 데이터 기반 승패 예측 및 핵심 승리요인 분석 — 4조

> **문제 정의 (질문 1문장 + 할 행동 + 제약)**
> - **질문**: 10분 시점의 경기 상태만 보고 최종 승패를 얼마나, 그리고 **왜** 맞힐 수 있는가?
> - **할 행동**: 관전·복기에서 "무엇을 봐야 하는지"의 우선순위를 근거와 함께 제시한다
> - **제약**: 지도학습 이진분류(무승부 없음) · 1순위 지표 정확도(승패 50.1:49.9 실측 균형) · scikit-learn · 1코어 · 4일

**결론 요약** — 로지스틱 회귀로 정확도 **0.7366 ± 0.0081**(분할 10회 반복 평균, 찍기 0.5010 대비 **+23.8%p**).
승리요인은 **골드 차이 > 경험치 차이 > 드래곤** 3개뿐이며(킬은 골드로 환산될 때만 의미),
정확도는 골드차의 함수다(접전 0.615 ↔ 크게 벌어진 경기 0.947).
프로 경기로 시점만 10분→15분 바꿔 비교하면 정확도가 +5%p 오르는데, 그 이득은 **접전 경기에만** 몰려 있다.

| [Oracle's Elixir 2022 프로 경기](https://lol.timsevenhuysen.com/matchdata/) | 통제 후 10,656경기 | **실험 B** — 10분 vs 15분 시점 비교 전용 |

한 줄 = 경기 한 판(10분 상태 + 최종 승패 `blueWins`). 결측 0 · 중복 0 · 승패 50.1:49.9 실측.
팀 MariaDB(`<팀DB명>.lol_matches_10min`) 적재, 피처 계산은 SQL 뷰(`v_diff13_*` 등)가 정본이고 CSV 폴백은 동일 계산식.
두 실험은 데이터·실력대·피처 수가 달라 **절대 수치를 서로 비교하지 않는다.**

**가장 중요한 규칙 — 분할 먼저.** 어떤 전처리보다 먼저 학습 7,903 / 시험 1,976으로 층화 분할(시드 42, `gameId` 정렬)하고 시험셋을 봉인했다.
시험셋은 **모델·피처 선택에 일절 쓰지 않았고**, 최종 평가와 해석(permutation·오류분석)에만 사용했다.

## 2. 파이프라인 — 5단계 13항목 매핑

| 단계 | 항목 | 우리 결과 |
|---|---|---|
| 1. 무엇을 풀 것인가 | ①문제번역 ②첫점검 ③EDA | 이진분류·정확도 확정(균형 실측) · 중복 피처 11개 발견 · 상관 순위(골드차 +0.51 1위) |
| 2. 기준선 | ④분할 ⑤전처리 ⑥베이스라인 | 층화 8:2 봉인 · StandardScaler는 Pipeline 내부 · 찍기 0.5009 |
| 3. 성능 | ⑦특성공학 ⑧모델탐색 | 중복 제거 후 **차이 피처 13개**(블루−레드, CV 0.7334→0.7369) · 8종 비교 → **로지스틱 회귀**(1위 0.7280±0.0163, 과적합 +0.0039) |
| 4. 신뢰 | ⑨평가검증 ⑩튜닝 | 5-fold std 0.0153·격차 +0.0022 통과 · 임계값 0.45~0.50 평평→0.5 유지 · 튜닝 생략(피처 2개=0.7328으로 전체와 동급 — 짜낼 것 없음) |
| 5. 남기기 | ⑪해석·오류분석 ⑫아티팩트 ⑬문서 | 요인 3개 두 방법 일치 · joblib 저장→복원→일치 assert · model_card(사용 금지 상황 포함) |

**로지스틱을 고른 이유**: 8종 중 정확도 1위 + 과적합 사실상 0 + **계수로 "왜"를 읽을 수 있음**.
랜덤포레스트(학습 1.0000, 격차 +0.2752)·HistGB(+0.1387)는 안정성 기준 위반으로 탈락 — 성능이 모델 복잡도의 정확히 역순이었다.

## 3. 결과

### 3-1. 성능 (실험 A)

| 지표 | 값 |
|---|---|
| **홀드아웃 정확도 (시드 42)** | **0.7394** — 찍기 0.5010 대비 **+23.8%p** |
| 교차검증(5-fold) | 0.7315 ± 0.0153 · 학습−검증 격차 +0.0022 |
| F1 / AUC / Brier | 0.7352 / 0.8150 / 0.1756 |
| **시드 10개 반복 (분할부터 재실행)** | **0.7366 ± 0.0081** (0.7277~0.7520) · 10/10회 하한 0.70 통과 |

> 단일 분할 값 0.7394는 반복 분포(0.7366±0.0081) 안의 한 표본이다.
> 발표에서는 **반복 평균과 함께** 말하는 것이 정직하다.

### 3-2. 승리요인 — "킬 말고 골드"

유의미한 요인은 3개뿐, 계수·permutation **두 방법에서 순위 완전 일치**, 시드 10회 반복에서도 10회 모두 1-2-3위 동일.

| 순위 | 요인 | 표준화 계수 | permutation |
|---|---|---|---|
| 1 | **골드 차이** | +1.231 | 0.185 |
| 2 | 경험치 차이 | +0.461 | 0.032 |
| 3 | 드래곤 차이 | +0.267 | 0.011 |

킬은 단독 효과크기 1.09(3위)로 강한 신호지만, 킬로 번 돈이 이미 골드차에 반영돼(상관 +0.92)
골드를 통제하면 계수가 음수(−0.11)가 된다. 정확한 해석: **"킬은 골드로 환산됐을 때만 의미가 있다."**
복기 관점에선 "싸움을 이겼나"보다 **"그 싸움이 돈 격차로 이어졌나"**를 봐야 한다.

### 3-3. 오류 분석 — 정확도는 골드차의 함수

| 10분 골드차 | 비중 | 정확도 |
|---|---|---|
| 접전 (<1,000) | 34.4% | **0.615** |
| 우세 (1,000~2,500) | 36.5% | 0.741 |
| 크게 우세 (2,500~4,200) | 20.4% | 0.859 |
| 사실상 결정 (4,200+) | 8.7% | **0.947** |

"정확도 74%"는 모델의 한계가 아니라 **접전 구간에선 10분 정보 자체가 승패를 못 가른다**는 데이터의 한계다
(시드 반복에서도 접전 정확도 0.598±0.017로 일관). 사이드 중립 KMeans 군집(경기 4유형)에서도 같은 결론:
일방적 경기(19%) 리드팀 승률 90% vs 접전 유형 68%.

### 3-4. 실험 B — 5분을 더 보면 (10분 vs 15분, 프로 경기)

같은 경기·같은 피처 5개·같은 분할에서 **시점만** 바꿨다 (블루 행만 남겨 중복 누수 차단, 10·15분 기록이 둘 다 있는 10,656판).

| 입력 시점 | 홀드아웃 | AUC | | 10분 상황 | 비중 | 개선폭 |
|---|---|---|---|---|---|---|
| 10분 | 0.7036 | 0.7729 | | 접전(<1k) | 52.1% | **+7.8%p** |
| **15분** | **0.7561** | **0.8344** | | 우세(1k~2.5k) | 37.5% | +3.1%p |
| 찍기 | 0.5230 | | | 크게 우세(2.5k+) | 10.4% | **±0.0%p** |

- 5분의 값어치는 **+5.25%p** (시드 10회 반복: +4.77±0.89%p, 10/10회 일관)
- 골드차 절대값 평균은 1,191→2,475로 2배, 접전 비율은 52%→27%로 반토막
- 10분 접전 경기의 **59.3%는 15분까지 골드차 1,000 이상으로 벌어진다** — 개선이 접전에 몰리는 이유
- 15분 계수: 경험치차 2.6배↑, CS차 절반↓ — 라인전이 끝나면 "성실히 파밍했나"보다 "실제로 얼마나 앞섰나"

**제목의 답** — 골드차 2,500+로 벌어진 경기(약 10%)는 10분에 사실상 판가름 나 있고(정확도 0.93, 5분 더 봐도 개선 0),
접전(52%)의 6할은 10~15분 사이에 격차가 벌어진다. **"초반에 다 기운다"도 "끝까지 모른다"도 틀렸다 — 경기 성격에 따라 다르다.**

## 6. 한계

- **접전은 10분 정보로 못 맞힌다** — 모델이 아니라 정보량의 한계. 실험 B가 그 이유(아직 안 갈렸을 뿐)를 보여줬다.
- **패치 한정** — 수집 시점 게임 버전의 결과. 메타가 바뀌면 재학습 필요.
- **실험 B는 프로 경기 한정** — 랭크에 그대로 적용 불가. 시점별 값이 있는 피처 5개만 사용. 10분·15분 두 점만 비교.
- **실험 B에 팀 단위 통제 없음** — 같은 팀의 경기가 학습·시험 양쪽에 들어가(GroupKFold 미적용) 절대 수치는 낙관적일 수 있다. 두 시점 간 **차이**는 같은 분할을 공유하므로 유효.
- **군집 k=4는 실루엣이 아니라 해석 편의로 고른 값** — 자연적 경계의 발견이 아니라 설명을 위한 구획.

## 부록 — 관전 포인트 (게임을 몰라도 이것만)

1. **골드(돈) 차이** — 4,200 이상이면 사실상 결정(적중률 95%), 1,000 미만이면 진짜 승부는 지금부터(적중률 62%)
2. **경험치(레벨) 차이** — 돈과 별개로 레벨이 앞서면 유리
3. **드래곤** — 팀 전체가 강해지는 버프, 초반에 챙긴 팀이 유리

**한 줄 요약 — 골드차 4천이면 끝난 경기, 1천 미만이면 이제 시작입니다.**
